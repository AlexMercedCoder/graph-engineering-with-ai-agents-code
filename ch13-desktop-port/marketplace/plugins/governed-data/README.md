# Governed data

Ask Claude a business question, such as net written premium by region last
quarter, and get the number with the definition of the metric it used.

## Use it

Install the plugin, then open its Connectors tab and connect the governed-data
connector, signing in with your company account. Ask your question in a chat or
a Cowork task. Claude finds the metric in the data team's catalog, generates
validated SQL, runs it under your own data access, and reports the result, the
definition, and the SQL.

## Data

Your questions and the generated SQL go to the governed-data connector, which
the data platform team runs. Results come back under your own access policies.
The plugin stores nothing itself.

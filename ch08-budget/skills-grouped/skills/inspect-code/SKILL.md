# inspect-code

This is a group of procedures. Pick the one that matches the request, read its file
with your file-reading tool, and follow it. Don't start the work before you've read it.

- Code review of a file or diff, including whether a change is safe to merge: `.claude/skill-groups/inspect-code/code-review.md`
- Explanation of what a module does, depends on, or is called by: `.claude/skill-groups/inspect-code/explain-module.md`
